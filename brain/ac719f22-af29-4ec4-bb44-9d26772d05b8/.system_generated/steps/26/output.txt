The search for ""ABDM" FHIR R4 JSON prescription lab report mock data India format" returned the following summary:
For developers working with the Ayushman Bharat Digital Mission (ABDM) ecosystem, health records must be structured as **FHIR R4 Bundles**[1][2][3]. These bundles use specific profiles defined by the National Resource Centre for EHR Standards (NRCeS)[4][5].

### Where to Find Official Examples
The most reliable source for "India format" mock data is the **NRCeS FHIR Implementation Guide (IG)**[1][2]. You can access the official JSON representations directly:

*   **Prescription Record:** [View Official Prescription-example-06](https://nrces.in/ndhm/fhir/r4/StructureDefinition/PrescriptionRecord) (Look for the "Examples" tab on the page)[1][6].
*   **Diagnostic Report (Lab):** [View Official DiagnosticReport-Lab-example-03](https://nrces.in/ndhm/fhir/r4/StructureDefinition/DiagnosticReportLab) (Look for the "Examples" tab)[2][7].

### Key Structure Requirements
When creating your own mock data, ensure your JSON complies with these ABDM-specific standards:

1.  **Bundle Type:** Must use `resourceType: "Bundle"` with `type: "document"`[1][2][8].
2.  **Profile Binding:** Every resource must reference the correct ABDM profile in the `meta.profile` field[1][2][9]:
    *   **Prescription:** `https://nrces.in/ndhm/fhir/r4/StructureDefinition/PrescriptionRecord`[6]
    *   **Diagnostic Report:** `https://nrces.in/ndhm/fhir/r4/StructureDefinition/DiagnosticReportRecord`[10]
3.  **Identifiers:**
    *   **Patient:** Use the ABHA number (system: `https://healthid.ndhm.gov.in`)[11].
    *   **Facility:** Use the HFR ID (system: `https://facility.ndhm.gov.in`)[11].
4.  **Clinical Coding:** 
    *   Diagnostic reports should use **LOINC** codes for lab observations[12][7].
    *   Ensure each test result is an individual `Observation` resource linked within the `DiagnosticReport`[12][7].

### Community Resources
For "copy-paste" ready, production-style examples that are often easier to read than the official spec pages, you can refer to community-maintained repositories[11][13]:
*   **GitHub Repository:** [Nirmitee-tech/abdm-fhir-bundle-examples](https://github.com/Nirmitee-tech/abdm-fhir-bundle-examples) provides simplified JSON bundles for various `hiTypes` including `Prescription` and `DiagnosticReport`[11][13].

### Validation Tool
Before submitting data, always validate your JSON against the ABDM IG using the [FHIR Validator](https://fhir.co.in/)[4]. This tool specifically checks if your resources conform to the Indian implementation requirements[4].

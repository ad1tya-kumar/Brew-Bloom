The ABDM (Ayushman Bharat Digital Mission) sandbox environment has transitioned to **V3 APIs** as the current standard, making them mandatory for new integrations[1][2]. Legacy v0.5 APIs are considered deprecated for new development[2].

### **Session Management (V3)**
The authentication flow for V3 requires a `client_credentials` grant type[3][4].

*   **Endpoint:** `POST https://dev.abdm.gov.in/api/hiecm/gateway/v3/sessions`[3][4]
*   **Request Body:**
    ```json
    {
      "clientId": "SBX_XXXXXX",
      "clientSecret": "XXXXXXXXXXXXX",
      "grantType": "client_credentials"
    }
    ```
*   **Mandatory Headers:**
    *   `Authorization`: `Bearer <accessToken>`[3][5]
    *   `X-CM-ID`: `sbx` (for sandbox)[3][4]
    *   `REQUEST-ID`: Unique UUID[3][4]
    *   `TIMESTAMP`: ISO 8601 format[3][4]

---

### **Key Differences: V0.5 vs. V3**
| Feature | V0.5 (Legacy) | V3 (Current) |
| :--- | :--- | :--- |
| **Discovery** | Asynchronous (Callbacks)[6][2] | Synchronous (Direct response)[7][2] |
| **Authentication** | Basic/Session-based | OAuth2 (`client_credentials`)[3][4] |
| **API Structure** | Distributed | Unified `/v3/` gateway endpoints[2] |

---

### **Resources for Integration**
*   **ABHA/HIP/HIU Milestones:** Integrations are typically organized into milestones:
    *   **M1 (ABHA):** Enrollment, login, and profile management[8][2].
    *   **M2 (HIP):** Discovery, linking, and data sharing services[8][2].
    *   **M3 (HIU):** Consent management and data requests[8][2].
*   **Documentation:**
    *   Official Sandbox Documentation: [sandbox.abdm.gov.in](https://sandbox.abdm.gov.in/)[9][10]
    *   Developer Forum: [devforum.abdm.gov.in](https://devforum.abdm.gov.in/)[9][10]
*   **Tools:** Community-maintained Postman collections (e.g., by Nirmitee.io) are widely used to test V3 endpoints for M1, M2, and M3 workflows[8][11].

**Note:** Always ensure your `clientId` and `clientSecret` are correctly configured in your sandbox environment settings. If you encounter `403` errors on specific endpoints, check the latest known issues on the [ABDM Developer Forum](https://devforum.abdm.gov.in/), as some sandbox environments may have specific gateway restrictions[9][7].

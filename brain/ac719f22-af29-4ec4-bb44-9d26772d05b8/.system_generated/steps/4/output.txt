The search for ""Tailwind CSS v4" Vite setup @tailwindcss/vite" returned the following summary:
To set up Tailwind CSS v4 with Vite using the `@tailwindcss/vite` plugin, follow these streamlined steps[1][2].

### 1. Install Dependencies
Run the following command in your project root to install Tailwind CSS and the official Vite plugin[3][4]:

```bash
npm install tailwindcss @tailwindcss/vite
```

### 2. Configure the Vite Plugin
Open your `vite.config.ts` (or `vite.config.js`) file and add the Tailwind plugin to your `plugins` array[3][5]:

```typescript
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
  ],
})
```

### 3. Import Tailwind in your CSS
Add the Tailwind import to your main CSS file (e.g., `src/style.css` or `src/index.css`)[3][5]:

```css
@import "tailwindcss";
```

### 4. Start Your Project
Run your development server to begin using Tailwind CSS[3]:

```bash
npm run dev
```

---
### Key Changes in v4
*   **No Configuration Files:** You no longer need `tailwind.config.js` or `postcss.config.js` for most setups[6][2].
*   **CSS-First Configuration:** Customizations and theme overrides are now handled directly in your CSS files using CSS variables[7][8].
*   **Simplified Pipeline:** The `@tailwindcss/vite` plugin handles everything, making the integration much faster and cleaner compared to previous versions[1][2].

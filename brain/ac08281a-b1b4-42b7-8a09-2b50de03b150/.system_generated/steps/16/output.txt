The search for ""tesseract.js" "createWorker" "hin+eng" or "hin", "eng" v5 v6" returned the following summary:
In **Tesseract.js** (including versions 5 and 6), you can enable support for multiple languages by passing an array of language codes to the `createWorker` function[1].

### How to use multiple languages
Instead of using a plus-separated string (like `hin+eng` used in some command-line Tesseract implementations)[2][3], Tesseract.js expects an **array** of strings[1].

#### Example Code
```javascript
import { createWorker } from 'tesseract.js';

(async () => {
  // Pass an array of language codes
  const worker = await createWorker(['hin', 'eng']);
  
  await worker.reinitialize('hin+eng'); // Optional: ensures initialization with both
  
  const ret = await worker.recognize('path/to/your/image.jpg');
  console.log(ret.data.text);
  
  await worker.terminate();
})();
```

### Key Points:
*   **Initialization:** While `createWorker(['hin', 'eng'])` is the standard way to specify languages[1], if you need to switch or add languages dynamically, you can use `worker.loadLanguage('hin+eng')` and `worker.initialize('hin+eng')`[4].
*   **Language Codes:** Ensure you use the correct ISO 639-2 codes (`hin` for Hindi, `eng` for English)[5][2].
*   **Version Compatibility:** The `createWorker` API signature remains consistent across v5 and v6, both of which support passing an array of languages for initialization[1][6][7].
*   **Performance Note:** Initializing with multiple languages can increase the initial load time and memory usage, as Tesseract must download and load the trained data files for every language specified[1].

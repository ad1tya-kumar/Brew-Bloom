In `qrcode.react` version 4, you can use `QRCodeSVG` or `QRCodeCanvas` to render QR codes[1][2]. Both components accept the same set of core props[1][2].

### Basic Usage Example

```jsx
import { QRCodeSVG, QRCodeCanvas } from 'qrcode.react';

// Using SVG
<QRCodeSVG value="https://reactjs.org/" />

// Using Canvas
<QRCodeCanvas value="https://reactjs.org/" />
```

### Advanced Example with Props
You can customize the QR code using various props, including `imageSettings` for embedding a logo or image[3][4].

```jsx
<QRCodeSVG
  value="https://example.com"
  title="My QR Code"
  size={128}
  bgColor="#ffffff"
  fgColor="#000000"
  level="L"
  includeMargin={false}
  imageSettings={{
    src: "https://example.com/logo.png",
    x: undefined,
    y: undefined,
    height: 24,
    width: 24,
    opacity: 1,
    excavate: true, // "digs" out the foreground to make room for the image
  }}
/>
```

### Available Props
| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `string` \| `string[]` | - | The value to encode. |
| `size` | `number` | `128` | The size in pixels. |
| `level` | `'L' \| 'M' \| 'Q' \| 'H'` | `'L'` | Error correction level. |
| `bgColor` | `string` | `'#FFFFFF'` | Background color. |
| `fgColor` | `string` | `'#000000'` | Foreground color. |
| `includeMargin` | `boolean` | `false` | Whether to render a 4-module margin (deprecated; use `marginSize`). |
| `marginSize` | `number` | - | Number of modules for the margin. |
| `imageSettings` | `object` | - | Configuration for an embedded image/logo[1][3][2]. |

**Note:** `QRCodeSVG` is generally recommended for its flexibility (scalability), while `QRCodeCanvas` is useful if you specifically need a canvas element (e.g., for easier integration with certain download/export workflows)[1][2].

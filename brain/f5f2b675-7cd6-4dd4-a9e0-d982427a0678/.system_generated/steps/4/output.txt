To integrate with the Ayushman Bharat Digital Mission (ABDM) ABHA sandbox environment for 2024–2025, developers should follow the official documentation and integration pathways provided by the National Health Authority (NHA).

### **1. Getting Started: Sandbox Access**
*   **Official Sandbox Portal:** Register your software or application on the [official ABDM Sandbox website](https://sandbox.abdm.gov.in/)[1][2].
*   **Developer Credentials:** After registration, you will receive your **Client ID** and **Client Secret**, which are mandatory for authenticating your API requests[3][2].
*   **Documentation:** Comprehensive API documentation is available through the [ABDM Sandbox Documentation portal](https://sandbox.abdm.gov.in/docs)[4][5].

### **2. API Integration Basics**
*   **Base URL (Sandbox):** Most ABHA V3 services use the base URL: `https://abhasbx.abdm.gov.in/abha/api`[6][7].
*   **Authentication:** 
    *   The first step is always to generate an access token using the `/api/hiecm/gateway/v3/sessions` API endpoint by passing your `clientId` and `clientSecret`[3][6].
    *   Subsequent API calls must include this token in the header as `Authorization: Bearer {{accessToken}}`[6][5].
*   **Common Headers:** Most endpoints require `REQUEST-ID` (a unique UUID) and `TIMESTAMP` (ISO 8601 format)[8][6].
*   **Data Security:** Sensitive information (Aadhaar, mobile, OTP, passwords) must be **RSA encrypted** using the public key provided by the ABDM platform before being sent in the request body[9][6].

### **3. Key Development Milestones**
Integration is typically structured around specific milestones to ensure compliance:
*   **Milestone 1 (M1):** Focuses on **ABHA creation and verification** (Aadhaar OTP, mobile OTP, etc.)[10][5].
*   **Milestone 2 (M2):** Focuses on **Health Information Provider (HIP)** and **Health Information User (HIU)** workflows, including linking health records and consent management[4][11].
*   **Facility Registry (HFR) & Professionals Registry (HPR):** Integration involves registering your health facility and medical professionals to obtain unique identifiers required for broader ABDM interoperability[4][1][2].

### **4. Useful Developer Resources**
*   **Developer Forum:** For technical queries and community support, visit the [ABDM Developer Forum](https://devforum.abdm.gov.in/)[5].
*   **Postman Collections:** Many developers use Postman to test API flows; importing the official ABDM collections can significantly speed up the development process[4][12].
*   **Compliance:** Ensure your application meets NHA guidelines before moving from the sandbox to the production environment[13][10].

Always ensure you are using the latest version of the APIs (currently **V3** for many ABHA services) as documented on the official portal, rather than older legacy versions[8][5].

To integrate with the Ayushman Bharat Digital Mission (ABDM) sandbox, follow this structured guide for 2024–2025. The integration is typically milestone-based (M1–M3) and requires compliance with national digital health standards[1][2][3].

### 1. Getting Started: ABDM Sandbox
*   **Register on the Sandbox:** Visit the [official ABDM Sandbox portal](https://sandbox.abdm.gov.in/) to create a developer account[4][5].
*   **Obtain Credentials:** After registration, you will receive your `Client ID` and `Client Secret`, which are required to generate authentication tokens for API access[1][6][4].
*   **Documentation:** Access the [API documentation](https://sandbox.abdm.gov.in/docs/healthid) for technical specifications, including request/response formats and error codes[1].

### 2. Milestone 1 (M1): Healthcare Professionals Registry (HPR)
The HPR module focuses on verifying healthcare professionals[7][2].
*   **Purpose:** Enables the registration and verification of doctors, nurses, and allied professionals[8][7].
*   **Key Integration Steps:**
    *   Integrate HPR APIs to verify professional registrations and link medical council numbers[4][9].
    *   Use Aadhaar or other approved documents for identity verification[10].
    *   Assign a unique Healthcare Professional ID (HP-ID)[8].

### 3. Consent Flow (M3 Integration)
The consent flow is critical for secure, patient-controlled health data sharing[11][12].
*   **Roles:**
    *   **HIP (Health Information Provider):** Stores and provides health records[5].
    *   **HIU (Health Information User):** Requests and consumes health records (e.g., a doctor viewing records)[11][5].
*   **Workflow:**
    1.  **Consent Request:** The HIU initiates a request for specific health data[11].
    2.  **Notification:** The Consent Manager (CM) notifies the patient[11].
    3.  **Grant/Deny:** The patient provides explicit, fine-grained consent[11][13].
    4.  **Data Exchange:** Once granted, the CM shares the consent artifact, allowing the HIP to transfer the requested data to the HIU via secure, encrypted channels[11][14].

### 4. Integration Checklist
*   **Authentication:** Ensure all API calls use the `Authorization: Bearer {token}` format, generated via the session API[1][6][15].
*   **Security:** All sensitive data (Aadhaar, mobile numbers, OTPs) must be RSA-encrypted before transmission[15].
*   **Compliance:** Ensure your system supports HL7 FHIR R4 standards for health data exchange[16][3].
*   **Certification:** After completing sandbox testing for all required milestones (M1–M3), apply for production certification through the ABDM portal to go live[17][2][5].

For specific technical queries, you can post on the [ABDM DevForum](https://devforum.abdm.gov.in/)[1].
